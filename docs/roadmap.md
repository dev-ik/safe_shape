# Roadmap

SafeShape `1.0.0` is the first stable API release.

The proposed product and release plan for the next major version is documented
in [roadmap-2.0.md](roadmap-2.0.md).

Included:

- runtime schemas and parser APIs;
- diagnostics and immutable validation errors;
- HTTP boundary helpers;
- JSON Schema export;
- CLI schema export, validation, and type generation;
- programmatic TypeScript declaration generation;
- programmatic validation reports;
- schema metadata annotations;
- umbrella `safe-shape` package.
- benchmark smoke suite for release evidence.
