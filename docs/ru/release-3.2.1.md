# Документационный patch SafeShape 3.2.1

[English](../release-3.2.1.md) | **Русский**

Статус исходной записи: публикация разрешена, проверка релиза выполняется.
Это перевод записи, не новое подтверждение публикации в registry.

Patch исправляет README пакетов npm. Все восемь пакетов, точные внутренние
зависимости и workspace lockfile используют 3.2.1. Runtime, public API и внешние
зависимости не меняются относительно 3.2.0; release checks проверяют архивы.

Изменения: композиция, pipelines, рекурсивные объявления и связи явно отмечены
как доступные с 3.2; описания sync/async Standard Schema и diagnostics согласованы
с runtime; EN/RU quick-start использует тихий модуль схем, логирование в приложении
и предварительное создание каталога snapshots. Исправлены метрики и бюджеты,
исторические значения оставлены историческими. README расширены ссылками на API
и production guides.

Обновляйте safe-shape и @safe-shape/* вместе. Миграции схем/snapshots/приложения
не требуется. [Запись 3.2.0 (EN)](../release-candidate-3.2.0.md) описывает возможности
и ограничения. Исключение независимого walkthrough для того релиза сохраняется;
автоматическая проверка документации не является новой человеческой проверкой.

Итоговая запись должна включить точный candidate, полный gate, сравнение архивов
с 3.2.0, registry install и проверку опубликованных README. Используется существующий
trusted-publishing workflow, без замены тега/архивов 3.2.0.
