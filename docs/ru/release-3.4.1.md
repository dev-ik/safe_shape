# SafeShape 3.4.1

[English](../release-3.4.1.md) | **Русский**

Статус: candidate; владелец разрешил публикацию.

Patch улучшает npm-документацию и поиск пакетов. Runtime-код, публичный API и snapshot formats совпадают с 3.4.0.

- README основного и API-пакетов дополнены примерами endpoint/client, OpenAPI export, snapshots, CLI commands и ограничениями transport.
- Во всех девяти package README используются абсолютные GitHub links, включая EN/RU language links, закреплённые на v3.4.1.
- Keywords добавлены во все девять package manifests.
- Русский список переэкспортов umbrella дополнен @safe-shape/api.
- Версии всех девяти пакетов и внутренние зависимости согласованы на 3.4.1.

```sh
npm install safe-shape@3.4.1
```

Миграция не нужна. [Свидетельства релиза](release-evidence-3.4.1.md) содержат выполненные проверки и статус публикации.
