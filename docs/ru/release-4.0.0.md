# SafeShape 4.0.0: прямое сравнение OpenAPI и независимый MCP

[English](../release-4.0.0.md) | **Русский**

Подготовленный релиз; пока не опубликован. Все десять пакетов имеют версию 4.0.0.
По-прежнему нужны Node >=20.10 и ESM.

`compareOpenApi(previous, next)` принимает OpenAPI YAML, JSON-строки или разобранные
документы через `@safe-shape/api` и `safe-shape`. Операции, запросы и ответы
сравнивает существующий движок совместимости SafeShape. Поддерживать копию схем
вручную не нужно. Поддержаны локальные рекурсивные ссылки, ограничения полей,
обязательность, наследование параметров, JSON media types, заголовки ответов и
explicit/range/default статусы. Неподдерживаемые конструкции дают manual-review
с указанием места в документе. Форматы требуют явной политики.
См. [руководство](openapi-comparison.md), [API](api/api.md) и
[YAML-пример](../../examples/openapi-comparison.mjs).

Zod, zod-to-json-schema и официальный MCP SDK удалены из production- и
dev-зависимостей. MCP-сервер использует валидацию SafeShape и собственную
ограниченную реализацию JSON-RPC/stdio: MCP 2025-06-18, инициализацию, tools,
отмену, лимиты и завершение работы. Тесты и примеры больше не используют SDK-клиенты.
Quality-замеры сравнивают candidate с предыдущим SafeShape baseline; тесты
мигратора исполняют только полученный SafeShape-код. Проверка зависимостей
распространяется и на установку из релизных архивов.

Это major-релиз: `createSafeShapeMcpServer` возвращает узкий интерфейс
`SafeShapeMcpServer` вместо SDK `Server`. CLI и manifest MCP, API схем и форматы
snapshots сохраняются. [Миграция с 3.x](migration-3-to-4.md) описывает transport-типы
и изменения для кода, использовавшего SDK-методы.

API tooling добавляет yaml 2.9.1; browser client entry остаётся отдельным.
EN/RU-руководства, API-справки, README пакетов и навигация обновлены под релиз.
Исторические отчёты сохраняют исходные версии и замеры. Публикация проходит
[release gate](release.md); локальные тесты не заменяют remote CI и проверку
новой реализации MCP реальным агентом.

Результаты локального gate: [проверка 4.0.0](release-evidence-4.0.0.md).
