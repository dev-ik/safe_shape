# Поддержка переводов

[English](../translations.md) | **Русский**

Актуальные пользовательские/API/операционные руководства и README пакетов имеют
русские версии. Английский источник задаёт имена API, флаги и коды; русское описание
сохраняет поведение и ограничения. Идентификаторы кода не переводятся.
Исторические release evidence и нормативные RFC/ADR остаются EN и явно отмечены.

Реестр docs/translations.json хранит пары, SHA-256 рассмотренных текстов EN/RU и
поимённые исторические исключения. Docs-check проверяет покрытие docs/API и README
пакетов, двусторонние ссылки языка и изменение источника/перевода. Новая актуальная
страница требует перевода; архивное исключение — явной причины и не должно скрывать
пользовательский справочник.

При изменении источника обновите и проверьте перевод до записи новых хешей обоих
файлов. Хеш подтверждает рассмотренный текст, но не качество или эквивалентность
перевода. Автоматической команды «принять всё» нет. Вместе проверяйте примеры,
defaults, домены, warnings, доступность по версиям и ссылки. Проверка входит в release gate.

EN-roadmap сохраняет историю; RU-roadmap ведёт к текущему релизу и помечает архив,
не представляя старые работы как незавершённые. Архивы пакетов включают оба README.
