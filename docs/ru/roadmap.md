# План развития SafeShape

[English](../roadmap.md) | **Русский**

Текущий стабильный релиз: [3.5.1](release-3.5.1.md), опубликован в npm.
См. [GitHub Release](https://github.com/dev-ik/safe_shape/releases/tag/v3.5.1).
MCP-сервер проверки контрактов и адаптер инструментов приложения уже выпущены;
см. [проверку публикации](release-evidence-3.5.md) и [историю релизов](releases.md).

Версия и состав следующего релиза в этом документе не согласованы. Новые
возможности требуют подтверждённого сценария пользователя, RFC для публичного
API, ADR для архитектуры, тестов и EN/RU-документации.

Текущие приоритеты — корректность runtime, стабильность вывода типов и API,
богатая диагностика и измеренная производительность. Существующие планы
описывают решения выпущенных релизов, а не текущий чеклист выпуска.

Английская страница хранит историческое планирование 2.x–3.1. Её старые статусы
не описывают текущее состояние: часть первоначального scope 3.2 вошла в 3.1,
а фактическая 3.2 выпущена с композицией и связями.

Приоритеты проекта: runtime first, стабильность API важнее числа возможностей,
неизменяемость, богатая диагностика, корректность перед производительностью,
производительность перед удобством. Новая публичная возможность требует RFC,
архитектурное решение — ADR, публичный API — тестов и документации.
Исторические release records и доказательства сохраняются на английском как
архив; текущие пользовательские инструкции доступны по-русски в [оглавлении](README.md).
