# Миграция с 3.x на 4.0

[English](../migration-3-to-4.md) | **Русский**

SafeShape 4.0 добавляет прямое сравнение OpenAPI и удаляет Zod и MCP SDK
из опубликованных пакетов и окружений разработки. Обновляйте все установленные
пакеты SafeShape вместе до 4.0.0. По-прежнему нужны Node >=20.10 и ESM.

Конструкторы схем, parsing, диагностика, совместимость, snapshots,
HTTP helpers и CLI сохраняют публичное поведение и форматы.

## Возвращаемый тип MCP-сервера

`createSafeShapeMcpServer()` теперь возвращает собственный `SafeShapeMcpServer`:
`connect(transport)`, `close()` и необязательные обработчики `onerror(error)` и
`onclose()`. Возвращаемый объект больше не является SDK `Server`. Нужно изменить
код, который импортирует этот тип или вызывает SDK-методы вроде `setRequestHandler`.
Сервер SafeShape предоставляет шесть встроенных инструментов проверки контрактов.
Другие инструменты приложения регистрируйте в собственном сервере с помощью
существующих `defineMcpTool` и `createValidatedMcpHandler`.

Собственные транспорты реализуют экспортируемый `McpTransport`: асинхронные
`start()`, `send(message)`, `close()` и необязательные callbacks
`onmessage(message)`, `onerror(error)`, `onclose()`. Подключение однократное;
закрытие идемпотентно. `McpJsonRpcMessage` описывает исходящий JSON-объект,
входные значения имеют тип unknown до проверки. `McpCallToolResult` описывает
текстовое содержимое, необязательные структурированные JSON-данные, флаг ошибки
и метаданные результата SafeShape-обработчика. Типы не требуют объявлений SDK.

CLI и формат manifest сохраняются без изменения конфигурации. Сервер явно
согласует MCP 2025-06-18 и объявляет только tools. Клиент должен завершить
initialize/initialized до обращения к инструментам. Методы, лимиты и отмена
описаны в [руководстве MCP](mcp.md). Клиент может использовать собственную
библиотеку протокола; SafeShape её не устанавливает.

## Документы OpenAPI

`compareOpenApi(previous, next)` из `@safe-shape/api` или `safe-shape` принимает
OpenAPI 3.0/3.1 в виде YAML, JSON-строк или разобранных объектов. Операции,
запросы и ответы сравнивает движок совместимости SafeShape. Существующий
`compareApiSnapshots` продолжает сравнивать API snapshots SafeShape. Формат
snapshot и формат OpenAPI не взаимозаменяемы. См. [прямое сравнение](openapi-comparison.md).

## Инструменты разработки

`npm run dependencies:check` запрещает Zod и MCP SDK в деревьях разрешённых
зависимостей. Consumer-проверки применяют то же правило к установкам из архивов.
Quality-замеры сравнивают candidate с SafeShape 3.1.0; исполнение benchmark
конкурирующей библиотеки удалено. Исторические отчёты сохраняют прежние результаты.
Мигратор по-прежнему читает исходный текст Zod, но ни он, ни тесты не импортируют
и не исполняют эту библиотеку.
