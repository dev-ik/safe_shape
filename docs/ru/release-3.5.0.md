# SafeShape 3.5.0: AI-контракты и MCP

[English](../release-3.5.0.md) | **Русский**

Статус: локальный кандидат, не опубликован. См. [результаты проверки](release-evidence-3.5.md).

## Состав

- Отдельно устанавливаемый `@safe-shape/mcp` с шестью stdio-инструментами:
  discovery, описания, точный экспорт JSON Schema, валидация, направленная
  совместимость и экспорт описаний MCP-инструментов.
- Типизированные инструменты приложения: проверка аргументов до исполнения и
  результата до успешного ответа; async-правила, преобразования и отдельные warnings.
- Фиксированный реестр/manifest разработчика. Вызовы по ID не выбирают пути
  модулей, не пишут файлы, не обновляют baselines и не выполняют бизнес-обработчики.
- Лимиты сообщений/ответов/concurrency и кооперативные отмена/deadline.
- Точный экспорт рекурсивных MCP-схем с корневым объектом и явной диагностикой.
- EN/RU-руководства, packaged README, исполняемые примеры и проверки установленного
  tarball. Все десять архивов сопровождаются SHA256SUMS.

## Совместимость и ограничения

Совместимый minor-релиз. Существующие схемы, CLI envelopes, форматы snapshots,
umbrella и browser import graphs сохраняются. Core и umbrella не получают
зависимость от MCP SDK. Все десять пакетов используют 3.5.0.

SDK закреплён на 1.32.1; нужны Node >=20.10 и ESM. Импортируемые модули и callbacks —
доверенный JavaScript без песочницы. Отмена не прерывает синхронный код, не
завершает async-код принудительно и не откатывает побочные эффекты. Opaque-правила
не ослабляются при экспорте. Payloads сохраняют мутабельность core; обёртки
отчётов и диагностика неизменяемы.

Удалённый HTTP-хостинг и профили AI-провайдеров вне этого релиза. Настройки
публикации/provenance и remote CI отделены от локальной проверки. Теги релиза,
remote push и npm-публикация в эту работу не входят.

См. [MCP](mcp.md), [API](api/mcp.md), RFC 0051 и ADR 0039.
