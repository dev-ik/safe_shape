# Документационный patch SafeShape 3.2.1

[English](../release-3.2.1.md) | **Русский**

Опубликовано 2026-09-25. Все восемь пакетов получили `latest: 3.2.1`;
README в registry совпали с исправленными файлами репозитория.

Patch исправляет README пакетов npm. Все восемь пакетов, точные внутренние
зависимости и workspace lockfile используют 3.2.1. Runtime, public API и внешние
зависимости не меняются относительно 3.2.0; release checks проверяют архивы.

Изменения: композиция, pipelines, рекурсивные объявления и связи явно отмечены
как доступные с 3.2; описания sync/async Standard Schema и diagnostics согласованы
с runtime; EN/RU quick-start использует тихий модуль схем, логирование в приложении
и предварительное создание каталога snapshots. Исправлены метрики и бюджеты,
исторические значения оставлены историческими. README расширены ссылками на API
и production guides.

Обновляйте safe-shape и @safe-shape/* вместе. Миграции схем/snapshots/приложения
не требуется. [Запись 3.2.0 (EN)](../release-candidate-3.2.0.md) описывает возможности
и ограничения. Исключение независимого walkthrough для того релиза сохраняется;
автоматическая проверка документации не является новой человеческой проверкой.

## Проверки и публикация

Подписанный тег `v3.2.1` указывает на `74ce3624f6c5e48d41ee7af535098c8d9b9dac07`.
Локальный `prepare:release` прошёл на Node 20.10.0: 274 теста пакетов, типы,
примеры, 29 benchmark-сценариев, установка потребителей, миграции, прежние
quality-бюджеты и оба аудита без уязвимостей.

[CI финального кандидата](https://github.com/dev-ik/safe_shape/actions/runs/36140635166)
прошёл на Node 20.10.0 и 24; архивы обоих заданий совпали с локальными.
Сравнение с 3.2.0 подтвердило неизменность JavaScript, деклараций, source maps
и прав файлов. Отличались только версии/внутренние зависимости и пять README.

[Workflow публикации](https://github.com/dev-ik/safe_shape/actions/runs/36141845086)
повторил полный gate, опубликовал восемь пакетов через trusted publishing и создал
[релиз v3.2.1](https://github.com/dev-ik/safe_shape/releases/tag/v3.2.1).
Версии, latest, SHA-512, скачанные npm-архивы, README registry и восемь GitHub
assets совпали с проверенными артефактами.

Чистый проект установил пакеты из npm. Проверены импорты, CLI doctor, связи,
рекурсивные декларации и вывод типов с TypeScript 5.9.2 и 7.0.2. Пять HTTP-запросов
покрыли неверный JSON/вход, сбои сервиса/ответа и успешную обработку после ошибок;
отклонения promises логгеров были изолированы.

Машиночитаемые записи сохранены в `.tmp/readiness-3.2.1/`. Тег и архивы 3.2.0
не менялись. Итоговые SHA-256 каждого архива приведены в
[английской записи](../release-3.2.1.md).
