# AGENTS

Mission:
Build the best runtime contract platform for TypeScript.

Core principles:
- Runtime first
- API stability over feature count
- Immutable schemas
- Rich diagnostics
- Correctness before performance
- Performance before convenience

Rules:
1. Never introduce breaking API without RFC.
2. Every public API requires documentation and tests.
3. Every architectural decision requires an ADR.
4. Avoid magic and hidden coercion.
5. Preserve strong type inference.
6. Keep packages loosely coupled.
