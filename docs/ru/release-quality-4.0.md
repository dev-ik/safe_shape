# Качество релиза 4.0

[English](../release-quality-4.0.md) | **Русский**

Документ заменяет требования к зависимостям конкурирующей библиотеки из
[критериев 3.1](release-quality-3.1.md). Требования к runtime, диагностике,
типам, совместимости, установленным consumer и регрессионным замерам сохраняются.
Исторические результаты не подтверждают изменённый candidate 4.0.

После установки root и quality lock-файлов запускайте `npm run release:check`.
Gate включает build, metadata, независимость зависимостей, EN/RU-документацию,
typecheck, тесты пакетов, исполняемые примеры, benchmark-бюджеты, установленных
consumer, quality fixtures, тесты миграции, оба audit и dry-run упаковки.
В root/quality и установках релизных consumer не должно быть Zod или официального
MCP SDK. Исходные migration fixtures разбираются как текст; исполняется только
полученный SafeShape-код.

Quality harness сравнивает candidate с SafeShape 3.1.0. Сохранены пять изолированных
замеров, чередование порядка, исходные результаты и бюджеты 20% времени/25% heap;
новые возможности сохраняют абсолютные бюджеты. Сравнение с конкурентом больше
не исполняется. См. [методику benchmark (EN)](../../quality/README.md).

Дополнительно проверяются прямое сравнение OpenAPI YAML/JSON, направления запросов
и ответов, диагностика неподдерживаемых конструкций, рекурсия и лимиты импорта;
MCP initialization, отмена, duplicate IDs, capacity, shutdown, framing и backpressure;
миграция с прежнего SDK return type. У каждого нового публичного API есть справка
и тесты. Версии пакетов/внутренних зависимостей согласованы; изменения контрактов
описаны в RFC/ADR.

Локальные проверки, remote CI на поддерживаемых Node, реальный MCP-агент и
публикация фиксируются отдельно. Wire test не доказывает поведение во всех агентах.
Контрольные суммы, публикация и registry verification описаны в [процессе релиза](release.md).
