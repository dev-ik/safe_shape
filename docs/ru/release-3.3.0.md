# SafeShape 3.3.0

[English](../release-3.3.0.md) | **Русский**

Статус: локальный релизный кандидат; не опубликован. Ещё необходимы CI на
финальном коммите и независимая проверка сценария разработчиком.

## Изменения

- `describeOutputBound(schema)` описывает верхнюю границу множества успешных
  выходов, включая последнюю проверяющую стадию pipeline.
- `checkSchemaConnection(producer, consumer)` доказывает совместимость этой
  границы со входом потребителя. Если включение не доказано, нужна ручная
  проверка: это не доказательство выдачи несовместимого значения производителем.
- Экспорт JSON Schema поддерживает явные `side: "output", mode: "output-bound"`.
  Безопасный экспорт возвращает предупреждение `json_schema.output.bound`.
  По умолчанию сохраняется точный режим; CLI и Standard JSON Schema также
  сохраняют точное поведение.
- Runtime повторно использует завершённые результаты определения асинхронности
  и неизменяемые результаты на слоях без проверок. Error, stack и диагностика сохранены.
- Актуальные руководства, API и README всех восьми пакетов доступны на русском.
  Проверки переводов обнаруживают пропущенные страницы и изменения проверенного текста.

Примеры и ограничения — в [руководстве по выходным границам](checked-output.md),
замеры — в [отчёте разработки (EN)](../release-evidence-3.3.md).
Локальные сценарии показывают улучшения, но не доказывают равенство с Zod.

## Обновление с 3.2.x

Ломающие изменения публичного API, формата snapshots и поведения по умолчанию
не предусмотрены. Существующие схемы и точные экспортёры не требуют миграции.
Включайте output bounds явно, когда подходит верхняя граница; непрозрачные
финальные преобразования остаются неподдержанными.

После публикации выполните `npm install safe-shape@3.3.0` либо совместно обновите
все используемые scoped-пакеты SafeShape до `3.3.0`. Требуются Node.js >=20.10 и ESM.
До публикации используйте локальные архивы из `npm run prepare:release`;
команда установки из registry не установит ещё не опубликованный кандидат.

## Квалификация релиза

`npm run prepare:release` запускает полный набор проверок и создаёт восемь
архивов в `release-artifacts/`. Перед публикацией изучите [процесс релиза](release.md).
Локальные автопроверки не заменяют CI на финальном коммите и независимую проверку
разработчиком, предусмотренную [планом 3.3](implementation-plan-3.3.md).
