# План развития SafeShape

[English](../roadmap.md) | **Русский**

Опубликованная версия: [3.2.1](release-3.2.1.md).

Текущая работа — [3.3: проверяемые выходы, runtime и документация](implementation-plan-3.3.md).
Уже реализованы композиция объектов, pipelines, рекурсивные TypeScript-объявления
и producer/consumer snapshots (3.2). Следующая задача — сделать проверенные выходы
полезными для export/containment и сократить измеренный runtime-разрыв с Zod,
сохранив диагностику и стабильность API.

Английская страница хранит историческое планирование 2.x–3.1. Её старые статусы
не описывают текущее состояние: часть первоначального scope 3.2 вошла в 3.1,
а фактическая 3.2 выпущена с композицией и связями.

Приоритеты проекта: runtime first, стабильность API важнее числа возможностей,
неизменяемость, богатая диагностика, корректность перед производительностью,
производительность перед удобством. Новая публичная возможность требует RFC,
архитектурное решение — ADR, публичный API — тестов и документации.
Исторические release records и доказательства сохраняются на английском как
архив; текущие пользовательские инструкции доступны по-русски в [оглавлении](README.md).
