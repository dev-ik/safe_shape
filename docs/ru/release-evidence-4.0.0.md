# Локальная проверка релиза SafeShape 4.0.0

[English](../release-evidence-4.0.0.md) | **Русский**

Контрольная точка: 2026-11-01. Локальные проверки candidate прошли; публикация
в npm, remote CI и walkthrough новой реализации MCP реальным агентом не выполнялись.
Все десять пакетов и точные внутренние зависимости имеют версию 4.0.0.

`npm run release:check` успешно завершился на Node v20.10.0, macOS arm64:

- Прошли build, metadata/границы зависимостей, typecheck и 356 тестов пакетов.
- Проверка документации прошла для 278 Markdown-файлов до добавления этой пары
  отчётов; последующие изменения только документации проходят повторный docs check.
- Прошли примеры, benchmark-бюджеты, tarball consumers и установка только umbrella.
  Последняя запускает оба CLI и проверяет MCP через stdio.
- Quality fixtures прошли пять серий замеров, интеграции установленных пакетов,
  declaration consumers и бюджеты candidate/baseline без Zod.
- Все три теста мигратора прошли без загрузки исходной библиотеки.
- Root и quality audit не обнаружили уязвимостей; dry-run упаковки прошёл.

MCP содержит 27 тестов: initialization, согласование версии, отмена,
capacity, duplicate IDs, malformed messages, закрытие, разделённый UTF-8 ввод,
backpressure и поздняя ошибка записи. API-пакет содержит 37 тестов, включая
19 новых сценариев сравнения OpenAPI. Запросы и ответы проверяются в разных
направлениях совместимости; неподдерживаемые конструкции дают manual-review.

`npm ls zod zod-to-json-schema @modelcontextprotocol/sdk --all` в корне и
`npm ls --prefix quality zod --all` возвращают пустые деревья. Проверки lock-файлов
и установленных consumer закрепляют этот инвариант. Optional peer metadata
сторонних инструментов не означает установленную зависимость. Исходные строки
мигратора и исторические benchmark-документы сохранены как текст; библиотека
не устанавливается и не исполняется.

Локальные логи: `.tmp/release-4.0.0/release-check.log` и
`.tmp/release-4.0.0/quality-report.json`. Quality report фиксирует исходники до
добавления этих итоговых текстов. Финальные архивы сохраняются отдельно в
`release-artifacts/4.0.0/` с `SHA256SUMS`; старые релизные артефакты сохранены.
Публикация проходит по [релизному процессу](release.md).
