# SafeShape 3.5.1: исправления документации

[English](../release-3.5.1.md) | **Русский**

Patch доставляет исправленную документацию через все десять npm-пакетов.
Статус публикации указан в [GitHub Release](https://github.com/dev-ik/safe_shape/releases/tag/v3.5.1)
и [результатах проверки](release-evidence-3.5.1.md).

## Изменения

- README, навигация и roadmap описывают текущий релиз; старые возможности
  и этапы разработки явно отнесены к истории релизов.
- Локальные CLI-примеры используют `npx --no-install`; npm scripts — `safe-shape`.
- MCP-руководство создаёт схему и manifest до запуска сервера. Примеры
  репозитория отделены от файлов, поставляемых npm.
- Русские руководства используют доступные RU-справочники; исправлена ссылка API umbrella.
- EN/RU README пакетов и их ссылки закреплены на `v3.5.1`.
- Чеклист публикации охватывает все страницы текущего статуса и проверку npm.

Публичный API, валидация схем и семантика MCP-handler не меняются. Runtime
version metadata и точные внутренние зависимости вместе переходят на 3.5.1.
По-прежнему нужны Node >=20.10 и ESM. Одна установка `safe-shape` предоставляет
`safe-shape/mcp` и MCP executable.

```sh
npm install safe-shape@3.5.1
```

Миграция не нужна. Trusted Publisher настроен для всех десяти пакетов.
