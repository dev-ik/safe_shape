# История релизов

[English](../releases.md) | **Русский**

Текущий стабильный релиз: **3.5.0**. Установка: `npm install safe-shape`.
Версии ниже указывают, когда появились возможности; новым проектам не нужно
устанавливать старую версию для их использования.

| Версия | Выпущенные изменения | Запись о релизе |
| --- | --- | --- |
| 3.5.0 | Валидация AI-инструментов и шесть MCP-инструментов; одна установка umbrella, entry `safe-shape/mcp` | [Описание](release-3.5.0.md), [проверка публикации](release-evidence-3.5.md) |
| 3.4.1 | Ссылки packaged README и npm metadata | [Описание](release-3.4.1.md), [проверка публикации](release-evidence-3.4.1.md) |
| 3.4.0 | Каталоги endpoints, валидируемый fetch-клиент, OpenAPI и проверка изменений API | [Описание](release-3.4.0.md), [проверка публикации](release-evidence-3.4.md) |
| 3.3.0 | Проверяемые выходные границы и доказательства связей схем | [Описание](release-3.3.0.md), [проверка публикации (EN)](../release-evidence-3.3.md) |
| 3.2.1 | Исправления документации | [Описание](release-3.2.1.md) |
| 3.2.0 | Неизменяемая композиция объектов, checked pipelines, рекурсивные TypeScript-объявления и связи producer/consumer | [Запись о релизе (EN)](../release-candidate-3.2.0.md) |
| 3.1.0 | Проверки контрактов проекта, представление ролей HTTP и ограниченные контрпримеры | [Запись о релизе (EN)](../release-candidate-3.1.0.md) |

Текущие руководства: [композиция](composable-contracts.md),
[связи](contract-connections.md), [проверяемые выходы](checked-output.md),
[API workflow](api/api.md) и [MCP](mcp.md).

Планы разработки и датированные измерения сохраняют решения и ограничения
своих этапов. Итог публикации смотрите в записи о релизе, актуальные инструкции —
в [оглавлении документации](README.md).
